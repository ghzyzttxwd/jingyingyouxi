# V0.5 测试记录

## 本版只调整时间显示与倍率

在 V0.4 已验证的广告直领奖、订单成长、TapTap 离线基础上，本版不改其他玩法逻辑。

### 时间倍率

原版时间系统是两态：

- 状态 0：1.0 秒阈值，约 1x
- 状态 1：0.5 秒阈值，约 2x

V0.4 曾把高倍阈值改成 0.125 秒（约 8x）。用户反馈 8x 过快，因此 V0.5 改为读取 float `1/6` 秒，约 6x。

关键 patch：

- `0x132FAD4`：原 `FMOV S1,#0.5` 改为 `LDR S1, literal`
- `0x12CA46C`：存放 float `1/6`（约 `0.16666667`）

### 右上角倍率显示

原版右上角按钮的显示语义是“下一档”：

- 实际 1x 时显示 2x（表示点击后切到 2x）
- 实际 2x 时显示 1x（表示点击后切回 1x）

V0.4 把 `2.0X` 文案替换为 `8.0X` 后，这个原版交互仍保留，因此出现“显示 8x 时实际为 1x，显示 1x 时实际为 8x”的现象。

V0.5 将 `0x132BD18` 的条件从 `CBZ` 改为 `CBNZ`，使按钮改为显示当前实际状态：

- 实际 1x -> 显示 `1.0X`
- 实际 6x -> 显示 `6.0X`

metadata 中原唯一 `2.0X` 文案同步替换为 `6.0X`。
